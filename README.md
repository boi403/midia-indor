# midia-indor

CMS de mídia indoor (TV corporativa): painel administrativo (`cms-admin`, React + Vite), servidor (`cms-backend`, Node + Express + SQLite) e player das TVs (`signage-player.html`).

## Rodar

No Windows, dê dois cliques em `iniciar-tudo.bat` e abra http://localhost:3000.

Para deixar rodando sozinho, com backup e alertas, veja [OPERACAO.md](OPERACAO.md).
